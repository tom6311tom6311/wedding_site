# Wedding week email

`wedding-week-reminder.html` is a responsive, table-based HTML email for the confirmed-attendee reminder. Its image URLs point to `https://marylovestomforever.com`, so deploy the accompanying images in `apps/web/public/images/email/` with the website before sending. Four email photos have illustrated counterparts ending in `-illustrated.jpg`; the original JPEG source assets and high-resolution PNG illustration masters remain alongside them.

Suggested subject: `下週六見！宇平與靖芸的婚禮`

Gmail does not provide a native "paste HTML source" composer. Open the HTML file in a browser, select its rendered message, copy it, and paste it into a new Gmail draft. Send a test to yourself first; the images must load from the deployed site for recipients to see them.
